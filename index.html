关于图片保存 ✕
Why · 为什么需要关注
P 值的参考图以「URL 或 base64 数据」的形式被记录。导出的 .json 在其他设备恢复时：网络图链接如果失效、本地上传的大图如果未嵌入数据，都可能丢失。所以建议提前规划图片来源。
How · 推荐做法
01
使用图床（首选） 将代表图片上传到 sm.ms、imgur、或个人云存储（OSS / S3 / R2），把得到的 URL 粘贴到 P 值卡片即可。导出 JSON 后图片完全可移植，体积小。
02
本地图片 = base64 通过「添加参考图」上传的本地文件会被自动转为 base64 数据嵌入。优点：完全离线，备份即恢复；缺点：JSON 文件会变大（每张图几百 KB 到数 MB）。
03
定期导出 JSON 每次重要更新后到「设置中心 → 导出配置文件」备份一份 .json，存至本地或同步盘（iCloud、Dropbox、Google Drive 等）。
Mix · 建议组合
· 代表性封面用外链，保持 JSON 体积小巧
· 关键素材 / 担心丢失的图用本地上传，让数据真正"打包带走"
· 每周或每月手动导出一次 .json，搭配图床形成双重备份

软件信息 / 使用教程
About · 这是什么
P-Value Manager 是一个收纳与管理 Midjourney 个性化参数（--p 代码）、提示词与词缀的工具：把好用的代码、词、搭配集中存起来，需要时一键拼出完整指令、随手复制。数据全部保存在你本地。
Tabs · 四个标签页
底部从左到右：资料库（首页总览）·提示词库（可复用的词）·P值库（你的 --p 代码）·我的（速记、我的提示词与词缀）。
How · 怎么用
01
P 值库收纳 --p 代码。点右下角 + 新建，进卡片可填写 7 位代码、添加封面参考图、配「组合搭配」和「赠送提示词」、打风格标签。
02
提示词库存放可复用的提示词，支持文件夹整理与标签筛选（多选标签＝需同时满足全部）；点卡片上的「复制」会一键拼出完整 MJ 指令（词缀＋正文 --raw --s --p）。
03
我的里可以随手记灵感、保存「我的提示词」，以及管理「词缀」（前缀起手式 + 后缀质感词），写好后可挂到提示词上一起复制。
04
资料库首页查看喜欢 / 收藏 / 词库 / P 值的数量统计、热门标签与最近内容；点统计卡或标签可快速跳转筛选。其中「P 值」与「词库」两栏只展示最近打开的 10 个（最近打开的排最前，方便快速找回常用）；完整列表请到底部「P值库 / 词库」查看。
Data · 数据与备份
数据会自动保存在本地，刷新或重开都不丢。重要更新后可在「设置中心 → 数据管理 → 导出配置文件」备份成 .json；换设备时用「导入配置文件」恢复。
Appearance · 外观
在「外观」里可切换主题（经典白 / 高级灰 / 高级黑 / 暖夜）、字号，以及手机 / 电脑视图（电脑上拉宽窗口会自动切换）。还可通过「导入主题代码」自定义整体配色。
Feedback · 反馈
如发现 bug 或有建议，欢迎到 QQ 群反馈：793109086。反馈时附上复现步骤或截图会更快定位问题。

本地保存 使用图床

数据管理
Export · 导出备份
把当前所有 P 值、词库、收藏与设置导出成一个 .json 文件，可保存到本地或转存到其它设备。建议定期备份。
Import · 导入恢复
选择之前导出的 .json 备份文件来恢复数据。导入会按文件内容覆盖 / 合并当前数据，操作前最好先导出一份当前备份。
Danger · 清除数据
清空本机保存的全部数据（P 值、词库、收藏、标签等）。此操作不可恢复，请务必先导出备份。
提示：背景图与外观设置只保存在本机，不会写入导出的 .json 文件，换设备后需要在「美化」里重新设置。
